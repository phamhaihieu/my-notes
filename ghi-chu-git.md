| Lệnh         | Công dụng                                                                                                 |

| ------------ | --------------------------------------------------------------------------------------------------------- |

| `git init`   | Khởi tạo một Git repository mới trong thư mục hiện tại.                                                   |

| `git add`    | Đưa các file thay đổi vào \*\*Staging Area\*\* để chuẩn bị commit. Ví dụ: `git add .`                         |

| `git commit` | Lưu lại một phiên bản của các thay đổi vào lịch sử Git. Ví dụ: `git commit -m "Thêm chức năng đăng nhập"` |

| `git status` | Kiểm tra trạng thái các file: file mới, file đã sửa, file đang được staged...                             |

| `git push`   | Đẩy các commit từ máy tính lên repository từ xa như GitHub.                                               |
